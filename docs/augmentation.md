# Обучение с MIT RIR

## Background + SpecAugment

Для всех трёх преобразований используйте `configs/augmented.yaml`:

```powershell
python -m ru_kws.train --config configs/augmented.yaml --data-root datasets/russian_commands_v001_clean_manual/russian_commands_v001_clean_manual --run-dir runs/bcresnet_augmented_001
```

Порядок: speed → PadCrop → RIR → background → gain → log-mel → SpecAugment → BC-ResNet.
Скорость: вероятность 0.5, коэффициент 0.90–1.10 с шагом 0.01.
Коэффициент >1 ускоряет запись. Используется полосоограниченный ресемплинг:
он немного меняет также высоту голоса (это не tempo-only time stretch).
Для команды замедление ограничено доступным местом в окне, чтобы не обрезать
фразу. Громкость: вероятность 0.8, равномерно от -6 до +6 dB, после смешивания,
поэтому SNR сохраняется. Усиление ограничено запасом до пика 1, без клиппинга.
Gain применяется ко всем классам; speed также применяется к unknown/background.
Оба преобразования отключены в val/test и в старых конфигурациях без их секций.
В `configs/rir.yaml` остаётся только RIR, baseline без аугментаций.

Background выбирается только из записей класса background в `splits/train.jsonl`.
Пересечения путей или заполненных `source_group` с val/test вызывают ошибку;
это не заменяет проверку скрытых дубликатов, если метаданные источников отсутствуют.
Вероятность смешивания 0.8, случайный SNR 5–20 dB относительно RMS всего окна,
включая padding (для короткой команды это мягче, чем SNR по активной речи).
Это настраиваемая SNR-политика, не исходный множитель амплитуды Qualcomm.
Короткий фон повторяется со случайным смещением, длинный обрезается случайно.
Смесь масштабируется целиком при пиках >1; соотношение сигнал/шум сохраняется.
Тишина не усиливается. Кеш содержит до 32 исходных фоновых записей на worker.

Смешивание применяется и к unknown; чистый background сохраняет собственную метку
и не получает дополнительного фона. Команда+шум сохраняет метку команды.
Фон должен действительно не содержать целевых команд/неоднозначной речи;
название класса само по себе этого не гарантирует. Прослушайте несколько смесей.

SpecAugment повторяет политику Qualcomm для BC-ResNet-8 (base_c=64):
две частотные маски со случайной шириной 0..6 и две временные 0..19 кадров,
независимо для каждой записи, заполнение 0 в log-mel, без time warping.
Шаг 10 мс означает максимум 190 мс на одну временную маску. Размеры
не увеличены пропорционально трёхсекундному окну. Источники:
[main.py](https://github.com/Qualcomm-AI-research/bcresnet/blob/master/main.py),
[utils.py](https://github.com/Qualcomm-AI-research/bcresnet/blob/master/utils.py).
Реализация самостоятельная и использует torch RNG вместо Python/NumPy RNG.
Ноль в log-mel является значением маски оригинала, а не физической тишиной.

SpecAugment вызывается только в тренировочном цикле и не входит в frontend,
чекпоинт весов или экспорт TFLite. Конфигурация сохраняется в чекпоинте.
Все три преобразования отключены при validation/test. Для notebook-цикла,
который вызывает `run_epoch` напрямую, создайте `build_specaugment(config)` и
передайте результат аргументом `specaugment` при обучении. CLI делает это сам.

RIR — импульсный отклик комнаты: он применяется свёрткой, а не смешивается
как фоновый шум. Реализация использует FFT-свёртку через torch, по принципу
[примера TorchAudio](https://docs.pytorch.org/audio/stable/tutorials/audio_data_augmentation_tutorial.html).

Датасет должен содержать `labels.json`, `splits/` и
`augmentation/mit_rirs/manifest.jsonl`. В текущей локальной структуре корень:
`datasets/russian_commands_v001_clean_manual/russian_commands_v001_clean_manual`.
При переносе в Colab включите новую папку `augmentation` в архив датасета.
Старый ZIP автоматически не обновляется.

Повторяемая подготовка из локального зеркала:

```powershell
python scripts/prepare_rirs.py --source D:/proj/grovety/wake_word/data/raw/magicrow/external/mit_rirs_hf --data-root datasets/russian_commands_v001_clean_manual/russian_commands_v001_clean_manual
```

Для включения используйте `configs/rir.yaml` вместо `configs/baseline.yaml`.
Либо добавьте в конфигурацию обучения:

```yaml
augmentation:
  reverb:
    enabled: true
    manifest: augmentation/mit_rirs/manifest.jsonl
    probability: 0.5
    max_rir_seconds: 1.0
    exclude_labels: [background]
```

Остальные параметры обучения остаются прежними. Старые конфигурации и
чекпоинты без секции augmentation работают без аугментации. Вероятность 0.5
и ограничение хвоста 1 секунда — начальные настройки для эксперимента.

Аугментация работает только в train: случайное выравнивание в окне → RIR →
frontend. Команды и unknown проходят одинаковое преобразование; background
по умолчанию исключён. Сильнейший пик RIR выравнивается к нулю; энергия
результата приводится к исходной, пики выше 1 предотвращаются общим снижением
усиления. Форма и метка сохраняются, хвост за границей окна отбрасывается.
Такое выравнивание является приближением прямого прихода и может удалить
ранние слабые отражения. Записи на диске и split-манифесты не изменяются.
PyTorch RNG обеспечивает повторяемость при одинаковом seed и порядке загрузки.

Val/test не используют RIR даже с enabled: true. Все добавленные RIR предназначены
для train; для оценки на новых комнатах нужен отдельный набор откликов/реальных
записей, не использованный при обучении.

Источник MIT сохранён в `SOURCE_README.md`; зеркало указывает license: unknown.
Исходные WAV копируются без изменения, SHA256 каждого файла указан в манифесте.
В локальном источнике фактически 270 WAV, хотя его README упоминает 271.
